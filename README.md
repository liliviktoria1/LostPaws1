# Lost Paws 🐾: Проєктування та розробка інтелектуальної Full-Stack системи розшуку тварин на основі нейромережевих архітектур

## 🎓 1. АНОТАЦІЯ ТА ВСТУП
Даний проєкт є комплексною програмною платформою, призначеною для автоматизації та оптимізації процесу реуніфікації загублених тварин із їхніми власниками. В основі системи лежить гібридна архітектура, що поєднує методи **математичної лінгвістики (Embeddings)**, **комп’ютерного зору (Vision AI)** та **систем реального часу (WebSockets)**.

Основною науковою новизною проєкту є впровадження «каскадного» методу верифікації об'єктів, що дозволяє ефективно використовувати обмежені ресурси безкоштовних API, зберігаючи при цьому високу точність ідентифікації.

## 🛠 2. АРХІТЕКТУРНІ ТА ТЕХНОЛОГІЧНІ РІШЕННЯ

### 2.1. Frontend: Клієнтська частина
Побудована на базі бібліотеки **React 18** з використанням суворої типізації **TypeScript**.
- **State Management:** Використано React Context API для керування станами автентифікації та глобальних сповіщень.
- **Geographic Information Systems (GIS):** Інтеграція бібліотеки **Leaflet.js** з підтримкою **Marker Clustering**. Це дозволяє рендерити великі масиви геоданих без втрати продуктивності браузера.
- **Localization (i18n):** Використано фреймворк `i18next`, що забезпечує повну доступність інтерфейсу українською та англійською мовами.

### 2.2. Backend: Серверна частина
Розроблена на платформі **Node.js** з використанням фреймворку **Express**.
- **ORM (Object-Relational Mapping):** Sequelize забезпечує високий рівень абстракції при роботі з PostgreSQL, автоматизуючи міграції та синхронізацію схем.
- **Security:** Автентифікація реалізована через **JSON Web Tokens (JWT)** з хешуванням паролів алгоритмом **Bcrypt**.
- **Real-time Communication:** Використано **Socket.io** для забезпечення миттєвого обміну повідомленнями та системними сповіщеннями.

## 🧠 3. ІНТЕЛЕКТУАЛЬНА ПІДСИСТЕМА АНАЛІЗУ (AI ENGINE)

### 3.1. Етап 1: Семантична векторизація
При реєстрації звіту текстовий опис ( breed, color, distinctive traits) обробляється моделлю `text-embedding-004`. 
- **Математична модель:** Текст перетворюється на вектор у 768-вимірному просторі.
- **Пошук схожості:** Використовується **Косинусна подібність**. Це дозволяє знаходити синонімічні описи, ігноруючи відмінності в лексиці.

### 3.2. Етап 2: Глибока візуальна верифікація (Vision LLM)
Для підтвердження збігів використовується модель **Gemini 2.5 Flash** (через механізм каскаду).
- **Алгоритм аналізу:** ШІ отримує два зображення та інструкцію для порівняння анатомічних особливостей тварин (форма вух, візерунки пігментації, наявність аксесуарів).
- **Обробка мови:** Система автоматично адаптує промпт до мови користувача (x-lang header), забезпечуючи reasoning (обґрунтування) українською або англійською мовами.

### 3.3. Стабілізація (Mutex & Cooldown)
Для дотримання Rate Limits (лімітів запитів) впроваджено **AI Controller**:
- Глобальна черга запитів.
- Обов'язковий Cooldown (затримка 6-10 секунд) між транзакціями.
- Автоматичний Retry при виникненні помилки 429.

## 📂 4. СТРУКТУРА БАЗИ ДАНИХ (ENTITY-RELATIONSHIP)

1.  **Users:** Центральна сутність, що зберігає профілі, контактні дані та посилання на сповіщення.
2.  **PetReports:** Основна таблиця даних. Містить поля:
    - `isReunited`: логічний прапор, що розділяє активні оголошення від успішних кейсів.
    - `embedding`: векторний тип даних для ШІ-пошуку.
    - `photos`: тип JSONB для зберігання масивів медіафайлів.
3.  **Conversations & Messages:** Реалізують відношення many-to-many між користувачами у межах конкретного контексту (Report ID).
4.  **Notifications:** Тимчасові об'єкти для інформування про збіги ШІ та вхідні повідомлення.

## 🚀 5. КЕРІВНИЦТВО З РОЗГОРТАННЯ ТА ЗАПУСКУ (SETUP GUIDE)

Дотримуйтесь цієї інструкції для коректного запуску проєкту на локальній машині.

### 5.1. Попередні вимоги (Prerequisites)
- **Node.js:** Версія 18.0.0 або вище.
- **PostgreSQL:** Версія 14 або вище.
- **Git:** Для клонування репозиторію.

### 5.2. Налаштування Бази Даних
1. Переконайтеся, що PostgreSQL запущений.
2. Створіть базу даних через консоль або інструмент (pgAdmin):
   ```sql
   CREATE DATABASE lost_paws_db;
   ```

### 5.3. Розгортання Бекенду (Server)
1. Перейдіть у директорію бекенду:
   ```bash
   cd LostPaws1/backend
   ```
2. Встановіть залежності:
   ```bash
   npm install
   ```
3. Створіть файл `.env` у корені папки `backend` та заповніть його:
   ```env
   PORT=8080
   NODE_ENV=development
   FRONTEND_URL=http://localhost:3005
   
   # База даних
   DB_NAME=lost_paws_db
   DB_USER=postgres
   DB_PASSWORD=ваш_пароль_до_postgres
   DB_HOST=localhost
   
   # Безпека та ШІ
   JWT_SECRET=фраза_для_шифрування_токенів
   GEMINI_API_KEY=ваш_ключ_з_google_ai_studio
   ```
4. Запустіть наповнення бази тестовими даними (рекомендовано для першого запуску):
   ```bash
   npm run seed
   ```
5. Запустіть сервер:
   ```bash
   npm start
   ```

### 5.4. Розгортання Фронтенду (Client)
1. Відкрийте новий термінал і перейдіть у директорію фронтенду:
   ```bash
   cd LostPaws1/frontend
   ```
2. Встановіть залежності:
   ```bash
   npm install --legacy-peer-deps
   ```
3. Створіть файл `.env` у корені папки `frontend`:
   ```env
   REACT_APP_API_URL=http://localhost:8080/api
   ```
4. Запустіть додаток:
   ```bash
   npm start
   ```

Додаток буде доступний за адресою: **http://localhost:3005**
